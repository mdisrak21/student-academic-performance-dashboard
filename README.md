# 🎓 Student Academic Performance Prediction Dashboard

An interactive data analysis and machine learning dashboard for exploring student academic performance and predicting mathematics scores.

## 📌 Project Overview

This project analyzes student academic performance data and provides an interactive Streamlit dashboard for exploring academic patterns and generating estimated mathematics scores using a machine learning model.

The project combines:

- Data analysis
- Data visualization
- Exploratory analysis
- Machine learning
- Interactive dashboard development

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze student academic performance
- Explore relationships between student characteristics and academic scores
- Compare performance across different subjects
- Examine the relationship between test preparation and academic performance
- Build a machine learning model for mathematics score estimation
- Develop an interactive web-based dashboard

## 📊 Dataset

The project uses the **Students Performance in Exams** dataset.

The dataset contains **1,000 student records** and **8 variables**, including:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## 🔎 Key Findings

Based on the dataset analysis:

- Average Math Score: **66.09**
- Average Reading Score: **69.17**
- Average Writing Score: **68.05**

Students who completed the test preparation course had higher average scores across all three subjects compared with students who did not complete the course.

### Average Performance by Test Preparation

| Test Preparation | Math | Reading | Writing |
|---|---:|---:|---:|
| Completed | 69.70 | 73.89 | 74.42 |
| None | 64.08 | 66.53 | 64.50 |

The dataset contains no missing values in the analyzed variables.

## 🤖 Machine Learning

A **Random Forest Regression** model was developed to estimate mathematics scores.

### Features Used

The model uses:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Reading Score
- Writing Score

### Target Variable

**Math Score**

### Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

The exact evaluation metrics are generated by the trained model and displayed directly in the Streamlit dashboard.

## 📈 Visualizations

The project includes several visualizations:

- Average scores by subject

## 💻 Interactive Dashboard

The Streamlit application provides:

### 📊 Dataset Overview
Displays:

- Total number of students
- Average Math Score
- Average Reading Score
- Average Writing Score

### 📈 Performance Analysis

Interactive charts showing subject-wise performance and test preparation comparisons.

### 🧠 Machine Learning Performance

Displays:

- MAE
- RMSE
- R² Score

### 🤖 Student Score Prediction

Users can enter student characteristics and reading/writing scores to generate an estimated Math Score.

### 🔍 Dataset Explorer

Users can explore the complete dataset directly inside the dashboard.

### 📥 Dataset Download

The application also provides an option to download the dataset as a CSV file.
